# GeekTimelines

Interactive, source-checked story maps for fictional universes. First universe: the Marvel Cinematic Universe.

- `index.html` — single-file prototype (being migrated to Next.js).
- Data is never invented: estimated years are marked `≈`, announced titles with no released material `⧗`, off-axis universes `✦`, and announced/inferred connections are drawn distinctly from confirmed ones.

Movie/series metadata and artwork from [TMDB](https://www.themoviedb.org/). This product uses the TMDB API but is not endorsed or certified by TMDB.
